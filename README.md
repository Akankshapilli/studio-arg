## Overview

**Studio ARG** is a live client project — a complete portfolio and business website designed and developed for a Hyderabad-based architecture and interior design studio. The project was delivered end-to-end: from discovery and wireframing through to UI design, frontend development, and live deployment on a custom domain.

The site is built to reflect the studio's identity — premium, minimal, and visually led — with smooth scroll animations, project showcases, and a strong mobile-first experience.

## Features

- ⚡ **App Router** — Next.js 15 with full TypeScript support
- 🎨 **Premium UI** — Tailwind CSS v4 with custom design tokens
- 🎞️ **Smooth Animations** — Framer Motion scroll-triggered transitions throughout
- 📱 **Mobile-First** — Fully responsive across all screen sizes
- 🖼️ **Project Showcase** — Dynamic project gallery with category filtering
- 🔤 **Custom Typography** — Editorial font pairing for a luxury studio feel
- 🌍 **Custom Domain** — Deployed on Vercel at `studioarg.in`
- 🚀 **Performance Optimised** — Image optimisation, lazy loading, fast page transitions

## Project Scope

This was a complete freelance delivery covering:

- **Discovery** — Client brief, content gathering, sitemap planning
- **Design** — Wireframes → high-fidelity Figma mockups → design system
- **Development** — Full Next.js implementation with TypeScript
- **Testing** — Cross-browser, responsive, performance testing
- **Deployment** — Vercel deployment + custom domain DNS configuration
- **Handoff** — Client walkthrough and documentation

## Getting Started

```bash
git clone https://github.com/Akankshapilli/studio-arg.git
cd studio-arg
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view locally.
